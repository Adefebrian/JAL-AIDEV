## How the sources combine

No source is "the" answer. For every section, JEV picks from the combined pool and judges every added layer (no fixed limit, `recipe-index.md` section 4): `ui.component_recipe` on product and marketing screens, `imm.recipe` on immersive sections. The build report records the recipe ID and source for every section, so any run can show which references it used.
