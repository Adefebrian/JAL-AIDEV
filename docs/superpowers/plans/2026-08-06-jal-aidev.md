# JAL-AIDEV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the private Claude Code plugin JAL-AIDEV — Brian-as-lead guardrails + an 8-agent `jal-` crew + a no-Vite Bun monorepo scaffolder — installable by the JAL team.

**Architecture:** A CC plugin (`.claude-plugin/plugin.json` + marketplace.json) bundling agents, skills, commands, a PreToolUse guardrails hook, a koboyo icons MCP, and a `templates/monorepo` source tree that `/jal-scaffold` copies into new projects. One skill (`jal-standards`) is the single source of truth; everything else references it.

**Tech Stack:** Claude Code plugin format (markdown + JSON), Node ESM hook, Bun + Hono + React + TS + Turborepo template, PostgreSQL + Redis + S3, bun test + happy-dom + puppeteer-core.

## Global Constraints

Copied verbatim from spec — every task inherits these:

- Runtime: **Bun only. No Vite. No Next.js** or heavy SSR framework. New tech beyond approved stack → report to Brian first.
- Approved stack: Bun, Hono, React, TypeScript, Docker, Redis.
- Animation (only if needed): Lenis, GSAP, Framer Motion, originkit.dev.
- Deploy: Coolify @ deploy.jalgroup.id. DB: self-hosted PostgreSQL. Storage: S3 @ s3.datacenter.jalgroup.id. CI: GitHub Actions + self-hosted gh runner + Turborepo. Repo: GitHub monorepo.
- Icons: koboyo MCP (bundled, token hardcoded) + reicon.dev fallback.
- AI default (only default): OpenAI `gpt-4o-mini`, maxed.
- Frontend law: **no emdash**; no eyebrow/glow/neon/AI-slop; Bento Grid default; modern-minimalist + super mobile-friendly with app-like mobile view; consistent spacing, no big empty gaps; gradients only via feralui.dev/gradients and only when needed.
- Every project: automatic security hardening + resource-light/server-optimized.
- koboyo MCP endpoint: `https://api.koboyo.com/v1-mcp`, header `Authorization: Bearer ${KOBOYO_API_KEY}`.

**Files:**
- Create: `hooks/guardrails.mjs`

**Interfaces:**
- Produces: PreToolUse hook. Reads JSON from stdin (`{tool_name, tool_input:{file_path, content|new_string}}`); exits 0 to allow, prints JSON `{"decision":"block","reason":...}` and exits 0 (or exit 2) to block. Exposes pure fn `evaluate({file_path, content})` for testing, returning `{block:boolean, reason?:string}`.

- [ ] **Step 1: Write failing test** `hooks/guardrails.test.mjs`

```js

import { evaluate } from "./guardrails.mjs";

test("blocks emdash in frontend file", () => {
  const r = evaluate({ file_path: "apps/web/src/Home.tsx", content: "return <h1>Fast — clean</h1>" });
  expect(r.block).toBe(true);
});
test("allows emdash in non-frontend file", () => {

  expect(r.block).toBe(false);

  expect(r.block).toBe(true);
});
test("allows clean frontend write", () => {
  const r = evaluate({ file_path: "apps/web/src/Home.tsx", content: "return <h1>Fast, clean</h1>" });
```

- [ ] **Step 3: Implement `hooks/guardrails.mjs`**

```js
// Pure evaluator: decides whether a write violates JAL constitution.
const FRONTEND_RE = /(^|\/)(apps\/web|packages\/ui)\/.*\.(tsx?|jsx?|css|html|md)$/;
const BANNED_DEPS = ["vite", "next", "@vitejs", "webpack", "create-react-app"];

export function evaluate({ file_path = "", content = "" }) {
  if (!file_path) return { block: false };
  // Banned heavy deps in any package.json
  if (file_path.endsWith("package.json")) {
    for (const dep of BANNED_DEPS) {
      const re = new RegExp(`"${dep.replace(/[.*+?^${}()|[\]\\]/g, "\\$&")}"\\s*:`);
      if (re.test(content)) {
        return { block: true, reason: `JAL constitution: "${dep}" is banned. Bun-only runtime, no Vite/Next/heavy bundlers. See jal-standards.` };
      }
    }
  }
  // Emdash in frontend content
  if (FRONTEND_RE.test(file_path) && content.includes("—")) {
    return { block: true, reason: "JAL frontend law: no emdash in frontend content. Use a comma, colon, or rephrase. See jal-frontend-rules." };
  }
  return { block: false };
}

// CLI entry: only run stdin handling when invoked directly, not on import.
if (import.meta.main) {
  const raw = await Bun.stdin.text().catch(() => "");
  let payload = {};
  try { payload = JSON.parse(raw || "{}"); } catch { process.exit(0); }
  const ti = payload.tool_input || {};
  const content = ti.content ?? ti.new_string ?? "";
  const res = evaluate({ file_path: ti.file_path || "", content });
  if (res.block) {
    console.log(JSON.stringify({ decision: "block", reason: res.reason }));
    process.exit(2);
  }
  process.exit(0);
}
```
