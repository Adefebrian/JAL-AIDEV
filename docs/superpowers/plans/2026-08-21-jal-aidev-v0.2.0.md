# JAL-AIDEV v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade JAL-AIDEV to v0.2.0: modular-monolith architecture enforced by a boundary checker, Bun-only runtime tightened, Go/Rust gRPC sidecars, a 13-agent FAANG-grade hierarchy, a red/blue security suite, 11 new commands, and a plain-language docs website with study cases.

**Architecture:** Extend the existing CC plugin (agents/skills/commands/hooks) and the `templates/monorepo` scaffolder. The template becomes a modular monolith (apps/api/src/modules/<domain> with single public index.ts + ports/adapters in core). A Bun boundary checker fails CI/hook/review on cross-module deep imports. A docs website (docs-site/) built with Bun static + Hono serve.

**Tech Stack:** Claude Code plugin format, Bun 1.3.14, Hono + hono/client RPC, React + TS, Turborepo, PostgreSQL (raw SQL migrations, no ORM), Go/Rust gRPC sidecars, changesets, bun test + happy-dom + puppeteer-core.

## Global Constraints

Verbatim from spec, every task inherits:

- Bun is the ONLY JS/TS runtime. Forbidden: vite, next, webpack, create-react-app, node, deno, ts-node, tsx, nodemon. Bun is runtime + package manager.
- Go/Rust ONLY as compiled gRPC sidecars under `services/`, opt-in, justified to Brian. Bun/Hono owns the proto contract.
- Modular monolith mandatory: `apps/api/src/modules/<domain>/`, one public `index.ts` per module, cross-module imports only via that index, infra (pg/redis/s3/ai) behind ports/adapters in `src/core/`.
- Every project is a Turborepo monorepo.
- Deploy ONLY to Coolify at `deploy.jalgroup.id`.
- Frontend law: no emdash anywhere in frontend content; no eyebrow/glow/neon/AI-slop; Bento grid default; minimalist + mobile app-like; consistent spacing; gradients only feralui.dev/gradients; icons koboyo then reicon.dev.
- Auto security hardening; resource-light; server-optimized. Default LLM: OpenAI gpt-4o-mini only.
- Agent/skill/command prefix `jal-`. Crew codename Pawang.
- No emdash (U+2014) in ANY shipped file that the guardrail treats as frontend, and none in docs-site content.

- [ ] **Step 3: Write `tools/check-boundaries.ts`** — Bun script:

```ts
// Fails if any module file imports another module except via its index,
// or imports a raw infra client instead of a core port.
import { Glob } from "bun";
const root = new URL("../apps/api/src/", import.meta.url).pathname;
const files = [...new Glob("modules/**/*.ts").scanSync(root)];
const RAW_INFRA = ["pg", "postgres", "ioredis", "redis", "@aws-sdk/client-s3"];
let violations: string[] = [];
for (const rel of files) {
  const self = rel.split("/")[1];
  const src = await Bun.file(root + rel).text();
  const importRe = /import[^"']*["']([^"']+)["']/g;
  let m;
  while ((m = importRe.exec(src))) {
    const spec = m[1];
    const sib = spec.match(/^\.\.\/([^/]+)(\/.*)?$/);
    if (sib && sib[1] !== self && sib[2] && !/^\/index(\.ts)?$/.test(sib[2]))
      violations.push(`${rel}: deep import into sibling module "${sib[1]}" (${spec})`);
    const deep = spec.match(/modules\/([^/]+)\/(.+)$/);
    if (deep && deep[1] !== self && !/^index(\.ts)?$/.test(deep[2]))
      violations.push(`${rel}: deep import into module "${deep[1]}" (${spec})`);
    if (RAW_INFRA.includes(spec))
      violations.push(`${rel}: raw infra import "${spec}"; use a core port instead`);
  }
}
if (violations.length) { console.error("BOUNDARY CHECK FAIL:\n" + violations.join("\n")); process.exit(1); }
console.log("BOUNDARY CHECK PASS");
```
